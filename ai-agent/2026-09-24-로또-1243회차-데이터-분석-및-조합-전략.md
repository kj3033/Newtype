### Context
로또(Lotto) 1243회차 예측을 위해 1회부터 1242회까지의 누적 데이터를 분석하였습니다. 최근 50회간의 구간별 흐름(Zone A~E)과 회차별 당첨 번호의 빈도(Frequency), 간격(GAP) 분석을 통해 차기 회차를 위한 최적 후보군(Final Pool)을 선정하고, 조합 간의 상관관계를 낮춘 포트폴리오를 구성하고자 합니다.

### Core
데이터 분석 결과를 바탕으로 도출된 22개의 후보 숫자와 이를 활용한 5가지 핵심 조합입니다. 각 조합은 특정 구간에 집중하거나 비우는 '비대칭 구조'를 활용하여 확률적 분산을 최적화하였습니다.

```python
# 최종 선정된 후보군 (FINAL_POOL)
final_pool = [2, 4, 7, 9, 11, 13, 16, 18, 19, 20, 22, 24, 29, 31, 32, 34, 37, 38, 41, 42, 43, 44]

# 포트폴리오 5개 조합 (Portfolio Strategy)
portfolio = {
    "A": [7, 18, 31, 34, 38, 43],  # 30번대 집중형
    "B": [2, 11, 16, 24, 29, 42],  # 핵심/보조 분산형
    "C": [4, 9, 22, 32, 37, 44],   # 역배치 구간형
    "D": [13, 19, 20, 24, 31, 41], # 10~20번대 연계형
    "E": [11, 18, 20, 32, 42, 43]  # 방어적 순환형
}
```

### Insight
통계적 분석 결과, 최근 30번대(Zone D)와 10번대(Zone B)의 강세가 뚜렷하며, 40번대(Zone E)에서는 주기적인 순환 패턴이 관찰됩니다. 조합 전략 수립 시, 특정 구간의 공백(Zero-Frequency Zone)을 의도적으로 배치하여 조합 간 독립성을 확보했습니다. 모든 조합 쌍 간 공통 숫자를 최대 2개 이하로 제한함으로써, 단일 조합의 실패 리스크를 방어하고 전체적인 커버리지를 극대화하는 전략을 취했습니다.
